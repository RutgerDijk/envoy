# Context: Research Phase

You are exploring code to answer a question or understand behavior.

## Constraints
- **Tools:** Read, Grep, Glob only (read-only — no changes)
- **Goal:** Understand, don't modify

## Approach
1. Start broad — find relevant files
2. Narrow down — read specific sections
3. Follow references — trace call chains
4. Summarize findings with file:line references

## Output Format
Summarize findings clearly:
- What you found
- Where (file:line references)
- Confidence level (certain / likely / uncertain)
- Any gaps in understanding
