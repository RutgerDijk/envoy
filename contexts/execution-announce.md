# Execution Announcement Discipline

Each layer, task, or step MUST be executed, not narrated.

Before executing, announce the step using one of these formats:

- Review layers: `Running Layer N: <name>...`
- Pickup tasks: `Task N: <name> (N/Total)`
- Finalize steps: `Running Step N: <name>...`

Do NOT write "I would do X" or "I did X" — actually do X. Execute the step, then report what actually happened.

**Violations:**
- Narrating without executing — execute the step, then continue.
- Skipping a step because it looks unnecessary — every step in the pipeline is required. If genuinely not applicable (e.g., tier-gated), say so explicitly and mark the step as skipped in the final report.
